# Expression Converter (Java)

This program converts expressions between:
- Infix → Postfix
- Infix → Prefix
- Postfix → Infix
- Prefix → Infix

## How to Run
1. Compile:
   javac ExpressionConverter.java

2. Run:
   java ExpressionConverter

## Example
Input: A+B*C  
Output: ABC*+
